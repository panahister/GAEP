# Security Policy Status

GAEP currently has no released software, supported runtime, or public security-response program. The repository still contains security-sensitive governance designs and may later define effectful AI capabilities.

## Current reporting path

Do not place secrets, credentials, personal data, unpublished exploit details, or confidential organizational information in a public issue or repository document. Until a formal security contact and disclosure policy are assigned, report sensitive concerns privately to the repository owner or the organization that granted repository access.

## Release blocker

Before external release or operational use, GAEP requires:

- an assigned security authority and private reporting channel;
- supported-version and response expectations;
- triage, remediation, disclosure and credit policy;
- dependency, model, adapter and capability vulnerability handling;
- incident and evidence-preservation procedures;
- update authenticity and revocation model;
- an approved platform threat model.

The candidate threat model is in `docs/next/06_GAEP_On_GAEP/007_PLATFORM_THREAT_MODEL.md`.
