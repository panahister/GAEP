# Mapping: Workspace Contents → WORKSPACE_CONTEXT_MAP.md + Folder READMEs (DISCOVERY)

## Purpose

Generates the **discovery layer** that makes the workspace navigable by any AI agent or human: a root `WORKSPACE_CONTEXT_MAP.md` (universal index) plus a folder-level `README.md` in each reference cluster (`backlog/`, `ux/`, `architecture/`). This ensures the AI in the workspace *knows what exists and where* — placing files in `backlog/` or `ux/` is not enough; the AI must discover them.

**Output:**
- `{workspace-root}/WORKSPACE_CONTEXT_MAP.md` — root discovery index (pointers to all areas)
- `{workspace-root}/backlog/README.md` — POLC cluster index
- `{workspace-root}/ux/README.md` — UXD cluster index
- `{workspace-root}/architecture/README.md` — ADLC cluster index

**Condition:** `WORKSPACE_CONTEXT_MAP.md` always (lists whatever clusters exist). Each folder README only when its cluster is present.

**Cluster:** Cross-cutting (discovery layer over all clusters).

**Type:** Derived index — NOT a governed element. Auto-regenerated on every generation and re-baseline. If the underlying files are correct, the map is correct by construction (see Governance Note).

---

## MANDATORY: Stage Sub-Role — Workspace Architect

During THIS activity, ALSO adopt the **Workspace Architect** mindset (navigability, information scent). ADDS a dimension — does NOT replace the primary role.

### Behavioral Shifts
- The map is a table of contents, not content — point, don't duplicate
- Optimize for "an AI lands here cold — can it find what it needs?"
- Every pointer must resolve to a real path (no dangling links)
- Derive counts/contents from the actual file manifest, never guess

### Anti-Patterns
- Do NOT copy story/wireframe content into the map — link to it
- Do NOT list files that weren't generated (cluster absent → omit its section)
- Do NOT hardcode counts — derive from the actual generated files

## Transformation Rules

### Rule 1: Derive, Don't Guess
All counts and lists come from the actual generated file manifest. If `backlog/epics/` has 10 epic files, the map says 10.

### Rule 2: Omit Absent Clusters
If a cluster wasn't generated (input absent), omit its section from the root map and skip its README.

### Rule 3: Pointers Only
The map and READMEs contain links + one-line descriptions. Never copy story/wireframe/ADR content.

### Rule 4: Auto-Regenerate
On every generation and re-baseline, regenerate these files fresh from the current manifest. They always reflect reality.

---

## Governance Note (NOT a Governed Element)

The context map and folder READMEs are **derived indexes**, not governed elements. GCE does NOT drift-scan them. Rationale: they are a table of contents derived from the file manifest — if the underlying files are correct, the map is correct by construction. DWG regenerates them on every re-baseline; staleness is structurally impossible.
