# GAEP for Kiro

Independently installable GAEP package for Kiro (identity `gaep.gaep-kiro`, version `0.2.0`). It reuses the compatible VS Code extension foundation and the shared, digest-verified Engine Host runtime, but is a distinct package: **VS Code success is not Kiro evidence**. Installation and workflow must be executed in Kiro.

See `docs/06_Roadmap/CS02_INSTALL_AND_RELEASE_GUIDE.md` for install, Engine Host bootstrap, provider prerequisites, model truth, uninitialized-Product behavior, execution limitations, test commands, upgrade, uninstall, and rollback.
