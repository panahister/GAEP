# External Standards and Frameworks Crosswalk

## Use rule

External material informs GAEP profiles, mappings, examples, and assurance. A citation does not import external language into GAEP Core, establish conformance, certification, endorsement, or equivalence, or grant reproduction rights. Every row below is unresolved for material reliance until exact source revision, access, assessor, mapping, and rights evidence close under GAEP-REG-003.

## Mapping relationship vocabulary

Every future mapping shall use one registered relationship value:

- equivalent for declared scope;
- narrower-than;
- broader-than;
- intersects;
- supports evidence for;
- conflicts-with;
- no material relationship;
- unknown or `not-assessed`.

Approximate similarity must not be labeled equivalence. `unknown/not-assessed` is a complete current mapping state, not permission to infer similarity. Each mapping binds exact source and GAEP revisions, rationale, assessor, owner, review date, limitations, and closure evidence.

## No-conformance-inference rule

No row currently supports a GAEP conformance claim, an external-standard conformance claim, certification, equivalence, endorsement, or release approval. Closing a row's source and rights uncertainty still does not establish conformance; a separate approved mapping and evidence case is required.

## Copyright and source control

GAEP should link to authoritative external sources and store only permitted quotations or summaries. Proprietary standard text must not be copied into the repository without appropriate rights. External-source loss or version change triggers review of affected mappings, profiles and conformance claims.
